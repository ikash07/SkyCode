[2026-10-03] TOP-RIGHT RUN 1ST-CLICK EXECUTION FIX & WINDOW-RESPONSIVE FONT SIZE
---------------------------------------------------------------------------------
TASK: 1. Fix top-right Run button requiring 2 clicks to execute code on first run.
      2. Automatically scale and adjust Monaco CodeEditor font size according
         to window/screen dimensions.

STATUS: COMPLETE & FULLY VERIFIED

ROOT CAUSE DIAGNOSIS:
  - 1st-Click Failure:
    1. Unmounted BottomPanel: When `isTerminalVisible` was initially false or toggled,
       `{isTerminalVisible && <BottomPanel ref={terminalRef} />}` unmounted BottomPanel
       completely from the DOM. On the first click of Run, `terminalRef.current` was null
       during that tick, requiring a 2nd click after re-mounting.
    2. Stale Active File: `runActiveFile()` called `setActiveFile(entryFile)` asynchronously
       without passing the resolved file directly to `startInteractiveExecution(file)`.
    3. Dirty/Unsaved Buffers: Newly typed or modified code was not saved to disk
       before starting the execution process, resulting in stale execution runs.

FEATURES & FIXES IMPLEMENTED:
  1. Instant 1st-Click Code Execution (WorkspacePage.jsx, BottomPanel.jsx, TerminalPanel.jsx):
     - Persistent BottomPanel Mount: Changed conditional rendering from unmounting
       to persistent CSS visibility (`style={{ display: isTerminalVisible ? 'flex' : 'none' }}`).
       `terminalRef.current` and its active WebSocket connection are now permanently
       available in memory and can execute on tick 0.
     - Direct File Parameter Forwarding: `BottomPanel.jsx` forwards `startInteractiveExecution(file)`
       directly to `TerminalPanel.jsx`, which prioritizes `overrideFile || activeFile`.
     - Auto-Save on Run: `runActiveFile()` inspects `openFilesRef` for dirty unsaved changes
       and saves `targetFile` to disk before triggering the runner process.

  2. Window-Responsive Dynamic Code Font Size (WorkspacePage.jsx, CodeEditor.jsx):
     - Real-Time Window Listener: Listens to window resize events with debounced
       re-render calculation.
     - Viewport Breakpoint Font Scale:
       * < 640px (Mobile): 11px
       * < 768px (Small Tablet): 12px
       * < 1024px (Tablet/Small Laptop): 13px
       * < 1440px (Standard Desktop / 1080p Split): 14px
       * < 1920px (Full HD 1080p): 15px
       * >= 1920px (2K / 4K Ultrawide): 16px
     - Monaco Dynamic Layout Updates: Added `editorRef.current.layout()` on `fontSize` change
       so Monaco recalculates line heights and glyph metrics without layout shift.
     - Enabled `mouseWheelZoom: true` in Monaco options for smooth Ctrl+Scroll font zooming.

========================================
  SECTION 5: HOW TO RUN
========================================

  FRONTEND:
    cd frontend
    npm install
    npm run dev          (starts on http://localhost:5173)

  BACKEND:
    cd backend
    npm install
    npm run dev          (starts on http://localhost:4000)
    
  REQUIREMENTS:
    - Node.js 18+
    - MongoDB (local or Atlas)
    - Docker (for code execution, optional — falls back to local)
    - Set MONGODB_URI and JWT_SECRET in backend/.env
