================================================================================
 3. NEXT-LEVEL UI DESIGN PROMPT
================================================================================

Design a premium online IDE called "SkyCode" with dark and light mode.

Layout: Header bar on top, 64px icon sidebar on left, 300px file explorer
panel, main code editor area with resizable terminal at bottom.

Dark mode: Deep navy canvas #0a0e1a, frosted glass panels with 16px blur,
soft blue accent #5b9aff, light text #e2eaf5, muted text #8496ad, subtle
blue-purple ambient glow in background corners.

Light mode: Warm off-white canvas #f4f5f7, clean near-solid white panels,
blue accent #3b6ef6, dark text #1a1d26, muted text #5e6678, ultra-soft
shadows with 0.06 opacity. Editor area is solid white #ffffff to #fafbfc.

Header: Rocket icon inside a blue-to-purple (#5b9aff → #7c3aed) gradient
rounded badge with breathing glow. "SkyCode" text with animated shimmer
gradient. "ONLINE IDE" as small uppercase subtitle. Theme toggle button
(Sun/Moon icon) on the right side.

Sidebar (64px): Vertical icon bar with rounded-3xl glass panel. Icons for
file explorer, search, settings. Bottom has a Play button with blue accent
color and glowing shadow. Active icon gets soft accent background tint.

File Explorer (300px): "EXPLORER" label + "Project files" heading. Action
buttons for new file, new folder, upload. File tree with chevron
expand/collapse. Hover reveals edit/delete icons. Selected file gets accent
highlight. Tree indent lines using subtle left border.

Editor Area: Top bar shows project name (uppercase tracking), language
badge pill (e.g. PYTHON), and Run button. File tabs with rounded top
corners, active tab has accent-soft background, close X appears on hover.
Code area uses Monaco-style syntax highlighting. Empty state shows centered
"Open a file to start editing" message.

Terminal (260px, resizable): Tab bar with Terminal, Output, Problems tabs.
Terminal header has terminal icon + "TERMINAL" label + status badge (amber
pulsing dot when running) + Run/Stop/Clear buttons. Terminal body is dark
monospace (#0d1117 background), green text for user input, blue for
commands, red for errors. Thin draggable resize handle that turns accent
blue on hover.

3 Screens to design:
  1. Workspace — the full IDE layout described above
  2. Dashboard — welcome greeting, create project form (name, description,
     language dropdown), project cards grid with hover lift effect
  3. Login/Register — centered glass card on ambient gradient background,
     SkyCode logo, clean rounded input fields, full-width accent button

Style: Glassmorphism with backdrop-blur, rounded corners (16px-24px), Inter
font for UI, smooth hover scale animations (1.01x), micro-interactions on
every interactive element. Premium feel like Linear × Vercel × Replit.

Do NOT use: pure black #000000, cold blue-grey light backgrounds, flat
basic inputs, harsh borders, generic fonts, or placeholder images.
